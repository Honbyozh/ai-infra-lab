# 每日学习记录

本目录只保存 32 周正式学习记录。启动准备、环境修复和其他计划外工作保存到 `docs/prestart/`，不得混入正式学习用时。

门禁通过并准备开始正式任务时，从 `docs/templates/daily-log.md` 创建记录。文件统一使用：

```text
YYYY-MM-DD-wNN-dN.md
```

日志中的验收项是开始当天的历史快照；同时必须记录主计划位置和 Git 基线，以便追溯后续计划变更。日志状态和实际时长是每日事实源，`docs/progress.md` 只做汇总索引。
