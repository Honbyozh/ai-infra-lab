# AI Infra 自学实验室

这是一个用于理解和实践 AI 基础设施的长期学习仓库。

## 当前阶段

当前不执行原有 32 周逐日计划，也不预设最终专项方向。本阶段只按 [AI Infra 全景认知方案](docs/ai-infra-landscape-orientation.md) 建立整体认知，并体验两个候选方向。

全景阶段完成后，再根据实际体验确定主方向、第二深度和第一阶段专项方案。原有逐日计划及其进度文件暂时保留为历史候选材料，不作为当前任务来源，也不更新其中的日期和状态。

## 机器角色

本仓库由学习机和实验机共享。每台机器通过被 Git 忽略的 `.machine.local.yaml` 保存本机角色，后续任务自动按角色能力执行，不需要反复修改共享文档：

- 学习机：阅读、知识笔记、设计、复盘和文档维护；实验步骤保持待完成。
- 实验机：文档、代码、环境配置、服务、实验和压测均可执行。

首次使用时按 [本机角色配置说明](environments/profiles/README.md) 选择模板；一台机器只需配置一次。

## 开始学习

1. 从全景方案的“模型生命周期与工作负载”开始，由 Agent 逐题讲解和追问。
2. 能够脱稿解释后继续下一个模块；不为每个模块创建日志。
3. 只在全景文档末尾维护“已经能解释”“未决问题”和一页方向选择备忘录。
4. 完成六个模块后，选择两个方向做代表性体验。
5. 体验完成后再制定专项学习路线。

## 记录原则

- 知识靠脱稿解释验收，不要求重复整理教材；
- 工程靠代码和测试验收；
- 性能靠脚本、原始数据和 Profiler 证据验收；
- 只记录路线决策、真实实验和难以重新获得的结论；
- 不维护每日打卡、复杂状态机或重复证据文档。
